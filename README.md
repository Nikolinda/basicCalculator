# -iPhone-Style-Calculator
A modern calculator inspired by the native iPhone Calculator app. Built using HTML, CSS, and vanilla JavaScript.

Features

iPhone-inspired user interface
Basic arithmetic operations (addition, subtraction, multiplication, division)
Keyboard support – perform calculations using your keyboard
Calculation history
Clear and delete functionality
Responsive design
Interactive calculator buttons
Technologies

HTML5
CSS3
JavaScript (Vanilla JS)
⌨️ Keyboard Support

The calculator supports keyboard input:

0–9 – Enter numbers
+ – Addition
- – Subtraction
* – Multiplication
/ – Division
Enter – Calculate result
Backspace – Delete last digit
Escape – Clear calculator
